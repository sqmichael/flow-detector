## Implementation Tasks

### Phase 1: Storage Layer

**Task 1.1: SQLite Database Setup**

File: `server/calling/memory/db.ts`

```typescript
// Schema
interface ThemeRecord {
  id: string;           // uuid
  theme: string;        // "vendor negotiation"
  context: string;      // "Dealing with pricing pushback from Acme Corp"
  last_mentioned: number; // timestamp
  expires: number;      // timestamp (last_mentioned + 4 weeks)
  source: 'call' | 'explicit';
}

interface PreferenceRecord {
  id: string;
  preference: string;   // "walks help after tense calls"
  created: number;
  permanent: true;
}
```

Dependencies: `better-sqlite3` (sync, simple, no async overhead)

**Task 1.2: Memory Service CRUD**

File: `server/calling/memory/service.ts`

```typescript
interface MemoryService {
  // Themes
  saveTheme(theme: string, context: string): ThemeRecord;
  getThemes(): ThemeRecord[];
  touchTheme(id: string): void;  // Update last_mentioned, extend expires
  deleteTheme(id: string): void;

  // Preferences
  savePreference(preference: string): PreferenceRecord;
  getPreferences(): PreferenceRecord[];
  deletePreference(id: string): void;

  // Cleanup
  expireOldThemes(): number;  // Returns count deleted

  // Query
  findThemeByKeyword(keyword: string): ThemeRecord | null;
  getMemorySummary(): string;  // For "what do you remember?" query
}
```

**Task 1.3: Decay Job**

On call-service startup:
- Run `expireOldThemes()`
- Log count if any deleted (no user notification)

### Phase 2: Hume Integration (Research Complete)

**Problem:** Current flow passes static config to Hume via URL. Need to inject dynamic memory context.

**Research Findings (Gemini, 2026-02-02):**

| Question | Answer |
|----------|--------|
| URL parameters for context? | No |
| Create/update configs via API? | **Yes** |
| Transcript webhooks? | **Yes** — `chat_ended` event |
| Tool use / function calling? | **Yes** |

**Chosen Approach: Pre-call Config Version**

1. Before each call, create new config version via Hume REST API
2. Inject memory context into system_prompt
3. Use new config_id in Twilio URL
4. Set up webhook for `chat_ended` to get transcript for theme extraction

**Task 2.2: Implement Hume Integration**

File: `server/calling/memory/hume-integration.ts`

### Phase 3: Voice Command Handling

**Problem:** Hume handles the conversation. We need to detect and process voice commands.

**Research Task 3.1: Hume Transcript/Event Access**

Check:
1. Does Hume provide real-time transcript webhook?
2. Can we get post-call transcript?
3. Does Hume support "tool use" or function calling?

**Task 3.2: Command Detection**

File: `server/calling/memory/commands.ts`

Commands to detect:
| Voice Input | Action |
|-------------|--------|
| "Remember that..." | Extract preference, save permanently |
| "Forget what I said about..." | Find and delete matching theme/preference |
| "What do you remember?" | Return summary |
| "Dismiss" / "Not now" | Ripcord: end call, purge session |

```typescript
interface CommandProcessor {
  detectCommand(transcript: string): Command | null;
  executeCommand(command: Command): CommandResult;
}

type Command =
  | { type: 'remember', content: string }
  | { type: 'forget', target: string }
  | { type: 'query' }
  | { type: 'ripcord' };
```

### Phase 4: In-Call Theme Confirmation

**Task 4.1: Theme Extraction**

At conversation end, extract likely theme from transcript.

File: `server/calling/memory/theme-extractor.ts`

```typescript
interface ThemeExtractor {
  // Use LLM to identify theme from transcript
  extractTheme(transcript: string): Promise<{
    theme: string;
    context: string;
    confidence: number;
  } | null>;
}
```

Use cheap model (DeepSeek) for extraction. Only save if confidence > 0.7.

**Task 4.2: Confirmation Flow**

At natural conversation end, agent asks:
> "Was that about the vendor thing, or something else?"

If user confirms → save/touch theme
If user says "something else" → extract new theme
If user ignores → don't save

  const { text, isFinal } = req.body;
  if (isFinal) {
    commandProcessor.process(text);
  }

// POST /call/ended - Post-call processing
app.post('/call/ended', async (req, res) => {
  const { transcript, duration } = req.body;
  if (duration > 180) {  // > 3 minutes

  }

## Success Criteria

1. Agent references previous themes naturally ("that vendor thing again")
2. User can query memory ("what do you remember?")
3. User can save preferences ("remember that walks help")
4. User can delete memories ("forget what I said about Steve")
5. Ripcord works instantly
6. Themes expire after 4 weeks of inactivity
